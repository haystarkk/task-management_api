TASK MANAGER

A RESTful API for managing personal and team tasks with priority tracking and user authentication.

## ✨ Key Features

### User Management
- Secure registration/login with JWT authentication
- Protected endpoints for user-specific data

### Task Operations
- **Create tasks** with titles, descriptions, and priorities
- **Organize tasks** by status (Complete/Incomplete)
- **Prioritize work** with three levels:
  - 🔴 High (Urgent)
  - 🟡 Medium (Important)
  - 🔵 Low (Backlog)
- Filter tasks by:
  - Completion status
  - Priority level
  - Due dates *(stretch goal)*

### Security
- Password hashing
- Token-based authentication
- User-specific data isolation
